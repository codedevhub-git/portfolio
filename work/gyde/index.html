The project

GYDE set out to centralize academic life: create a course with a syllabus and curriculum, publish class notes with real math, run assignments and grading, take part in journal-style peer review, follow a research feed, and build an academic CV. I carried it through several rebuilds over the years, from Node/MongoDB to a Flask + React version, up to a 2025 demo.

Courses

Create a course, a syllabus and a curriculum, and let students join with an entry code.

Under the hood

Built with

  • MongoDB
  • EJS
  • LaTeX
  • Cloudinary
  • Flask + React (v2)

Different versions explored different stacks: Express + MongoDB with server-rendered views, a Python Flask API with a React front end, and LaTeX rendering on the server for math. Names and photos in the demo data have been anonymized in these screenshots.
