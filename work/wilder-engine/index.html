The project

Everything I built for my first 3D world, pulled apart into pieces any game can use: endless generated land, animals that graze, flee, hunt and migrate, weather, the sea, seasons, combat, building, crafting, villages, cars, multiplayer and a one-command installer.

Living world

Generated terrain, biomes, day and night, seasons, weather and the sea.

Creatures that learn

Animals and enemies hunt by sight and sound, and each species learns from encounters (“Creature minds”).

Gameplay kit

Guns, bows, blades and spells, a bag and storage, crafting, building, quests, conversations and vehicles.

Tooling

A creature creator, a dev console, a performance test that tunes itself to the PC, and an installer.

Under the hood

Built with

  • Godot 4.7
  • GDScript
  • Node.js world server
  • TypeScript

Modular: each game keeps its own folder, and the engine updates in place with one command. Two games run on it today, Míani and The Hollow Wild.
