The project

Trak30 is a privacy-first budget tracker that installs like an app. Sign up without an email, snap a photo of a receipt and let it read the amount and date, automate recurring bills, and see the month as a ring of spending categories. It learns how you categorize things and flags sneaky recurring charges. The servers are paused right now; these screens come from my latest code running with demo data.

Spending ring

The month at a glance: every category around your balance.

Receipt scanning

Take a photo, and the app reads the amount and date (Tesseract OCR).

Recurring bills

Rent, insurance and utilities scheduled once, with reminders before they’re due.

Money-leak alerts

Spots small recurring charges that add up.

Calendar & analytics

Daily totals on a calendar, savings rate, runway and trends.

Under the hood

Built with

  • Node.js
  • Express
  • MongoDB
  • Tesseract.js
  • Chart.js
  • PDFKit
  • node-cron
  • Socket.io admin
  • PWA

Privacy by design: username and password only, with security questions and a one-time recovery code instead of an email. A separate real-time admin dashboard watches usage over Socket.io. Nightly jobs handle recurring bills and reminders.
