The project

NAHUAL is a private assistant that runs on a Windows PC. It remembers what matters across months, can control the computer and the browser, works by voice, and connects to Google tools only if you allow it. I use it every day and keep hardening it with a large automated test suite.

Long-term memory

Remembers facts, prices, people and decisions over months, and asks before trusting an old number.

PC & browser control

Opens apps, manages files and drives Chrome through its own extension, NAHUAL Link.

Voice

Talk to it and it talks back.

Google tools (opt-in)

Email, calendar, contacts, tasks and Drive, only when you ask.

Self-repair & game mode

Watches its own health and steps aside while you play.

Under the hood

Built with

  • Python 3.11
  • aiohttp
  • Local LLMs (GPU)
  • Chrome extension
  • Windows installer

An async Python core on 127.0.0.1 with token auth, a JS desktop UI, local speech and vector memory, and honesty guards that check its own claims and promises. Before NAHUAL I designed an “AI Desktop Companion” in TypeScript: a kernel, a plugin SDK and 20+ engines (memory, mood, personality, voice, automation), about 31k lines with 87 test files.
