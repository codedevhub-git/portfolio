Software de escritorio

Software de escritorio que funciona sin internet y se instala con un clic.

No todo pertenece a la nube. Construyo apps de Windows que guardan los datos en su propia computadora, funcionan sin internet y se entregan con un instalador normal. Puedo agregar licencias si quiere vender la app.

Lo que obtiene

Desarrollo de software de escritorio para Windows

  • Instalador de Windows (.exe), con actualizaciones automáticas opcionales
  • Base de datos local (SQLite) y respaldos de un clic
  • Licencias ligadas al equipo y niveles para vender software
  • Acceso desde el teléfono por la red Wi-Fi local
  • Exportación a PDF / Excel
  • Apps en la bandeja, superposiciones y atajos de teclado

Software de escritorio: preguntas

¿Puedo vender el software que me construyan?

Sí. ShopTrack, por ejemplo, tiene claves de licencia ligadas al equipo, niveles y una versión de demostración.

¿También para Mac?

Las apps de Electron también se pueden construir para macOS y Linux. Pruebo primero en Windows.
