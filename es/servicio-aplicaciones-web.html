Apps web a la medida: preguntas

¿Cómo empezamos si solo tengo una idea?

Con una sesión corta de planeación. Convierto la idea en una lista de pantallas y una primera versión que podemos lanzar, con precio fijo para esa fase.

¿Cuánto cuesta el hosting de una app?

Normalmente desde unos pocos dólares hasta alrededor de $30 al mes por una base de datos y servidor a escala pequeña. Le digo el número exacto antes de empezar.
